# Clasificaci-n-muertes-maternas---CIE-MM
El siguiente código permite clasificar las defunciones maternas a partir de las estadísticas vitales que sigan CIE-10 e implementando otras causas de defunción que son de alta incidencia en América Latina. 

El script denominado codigo_universal_cie_mm provee el diccionario oficial CIE-MM y una función generalizada para procesar bases de datos de mortalidad materna de cualquier país.
